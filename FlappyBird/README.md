# Flappy Bird

A full-screen Flappy Bird clone built with Python and Pygame.

## Features

- Full screen gameplay
- Smooth bird animation with wing flapping
- Dynamic difficulty (gap size decreases, speed increases with score)
- Particle effects on scoring
- Sound effects (jump, score, hit)
- High score tracking per session
- Gradient sky background with animated clouds
- Detailed graphics with ground texture

## Controls

- **SPACE** or **Mouse Click**: Flap/Jump
- **ESC**: Return to menu or exit

## Installation

```bash
pip install -r requirements.txt
```

## Running the Game

```bash
python run_flappy.py
```

Or run directly:

```bash
python -m newgame.flappy.game
```

## Requirements

- Python 3.7+
- Pygame 2.0+
